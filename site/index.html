Why

Because every other one wanted a card on file.

I needed a dark basemap for my own projects. Everything decent was behind an API key, a signup, a monthly quota, or a billing page — and most of the free alternatives look like someone inverted a light basemap and called it a night.

So I made one. It's OpenStreetMap data in PostGIS, styled by hand in QGIS Desktop, rendered by QGIS Server, and cached as ordinary XYZ tiles. The cache does almost all the work, which means leaving it open to everyone costs me very little. So it's open to everyone.

No key. No signup. No tracking. No quota page. Just a URL.

The whole thing is open source under the MIT licence — the tile cache, the QGIS Server setup and this page are all on GitHub. If you would rather not depend on me staying online, run your own copy.

How to use

Pick your tool.

Every snippet already includes the attribution you're required to display.

  1. Open the Browser panel.
  2. Right-click XYZ Tiles → New Connection…
  3. Name it mella basemap and paste the URL below.
  4. Set Max. Zoom Level to 20, then OK.
  5. Double-click the new entry to add it to your project.
${BASEMAP_PUBLIC_URL}/tiles/countries/{z}/{x}/{y}.png

Set the attribution (queeniemella.cc + OpenStreetMap) under Layer Properties → QGIS Server → Attribution, or in the layer metadata, so it travels with anything you export.

const map = L.map('map').setView([48.85, 2.35], 12);

L.tileLayer('${BASEMAP_PUBLIC_URL}/tiles/countries/{z}/{x}/{y}.png', {
  maxZoom: 20,
  attribution: '© <a href="https://queeniemella.cc">queeniemella.cc</a> | © <a href="https://www.openstreetmap.org/copyright">OpenStreetMap</a> contributors'
}).addTo(map);

Attribution

You do have to credit OpenStreetMap.

The cartography is queeniemella.cc's, but the geometry underneath is the OpenStreetMap database, which is licensed ODbL. Rendered tiles count as a "Produced Work", and that licence requires the credit to be visible wherever the map is. Styling it differently doesn't change what the data is.

It's one line. Drop it anywhere the map is visible:

© <a href="https://queeniemella.cc">queeniemella.cc</a> | © <a href="https://www.openstreetmap.org/copyright">OpenStreetMap</a> contributors

Most libraries render this for you if you pass it as the layer's attribution — every snippet above already does.

Fair use

There's no key, so please don't make me add one.

Fine

Personal projects, side projects, client work, internal dashboards, prototypes, teaching, research, commercial use. Genuinely — go ahead.

Not fine

Bulk-scraping the pyramid to build your own offline copy, or pointing a render farm at it. That's the one thing that would actually cost me money.

If you need volume

Get in touch before you start. It's easier to help you than to notice the traffic and start blocking things.

No uptime guarantee and no support contract; this is a thing I host, not a product I sell. If you want one, host it yourself, its open source.
